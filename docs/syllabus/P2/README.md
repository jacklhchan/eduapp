# P2 Syllabus Index

Stage: **P1-P6 / Primary**

八個學習領域打底，並逐步以小學科學及小學人文取代常識科。

## EDB Stage Content Snapshot

Source basis: EDB Primary Education Curriculum Guide (2024), KLA curriculum documents, and 2025/26 subject implementation notes.

- 小學階段建基於八個學習領域，強調兩文三語、探究思維、價值觀、身心健康和自主學習。
- 2025/26 起小學科學和小學人文先在 P1、P4 推行，並於 2027/28 延展至所有級別，逐步取代常識科。
- 科技教育包括運算思維和編程；高小公開資助學校採用加強編程教育單元。
