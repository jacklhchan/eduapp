# HKEDB K1-S6 Syllabus Reference

最後更新：2026-06-01

本文件保存 EduPass AI 使用的香港教育局（HKEDB / EDB）K1-S6 課程與科目框架，作為日後 curriculum mapping、OCR review、弱點追蹤、練習生成與 Portfolio tagging 的參考。

更細的 per-year / per-subject Markdown 已拆到 `docs/syllabus/`：

- `docs/syllabus/README.md`：全級別索引
- `docs/syllabus/P1/mathematics.md`：例子，P1 數學
- `docs/syllabus/P1/primary-science.md`：例子，P1 小學科學
- `docs/syllabus/S1/citizenship-economics-society.md`：例子，S1 公民、經濟與社會
- `docs/syllabus/S4/citizenship-social-development.md`：例子，S4 公民與社會發展

## 使用邊界

- 本文件是 app 內部 reference，不是 EDB 官方文件副本。
- 內容以官方來源的科目框架、學習領域、年級覆蓋、過渡安排、EDB-derived 課程內容摘要與 app mapping 為主。
- 具體課程目標、評估細則、學習內容細項，仍以 EDB 原文 PDF / 網頁為準。
- 分散式 subject MD 保存的是結構化轉述與 mapping，不保存整份 EDB PDF 長篇逐字內容。
- 不把上載功課或商業教材內容混入官方 syllabus；題目 mapping 只標示 topic / skill / source。

## Cross-stage Summary

| Stage | Official framing | EduPass AI mapping |
| --- | --- | --- |
| K1-K3 | Kindergarten curriculum uses five developmental objectives and six learning areas. | Portfolio evidence, whole-child development, language / self-care / creativity tags |
| P1-P6 | Primary curriculum covers eight KLAs. From 2025/26, Primary Science and Primary Humanities start at P1 and P4 and progressively replace General Studies by 2027/28. | OCR review, weakness dashboard, practice generation, portfolio learning evidence |
| S1-S3 | Junior secondary curriculum covers eight KLAs. Chinese History is an independent compulsory subject. CES begins replacing Life and Society from S1 in 2024/25 and extends to all JS levels by 2026/27. | Subject expansion roadmap, source-based review, concept maps |
| S4-S6 | Senior secondary curriculum includes core subjects, elective subjects, Applied Learning, Other Languages and Other Learning Experiences. | Senior secondary pathway planning, elective subject evidence, issue inquiry |

## App Data Model Mapping

| App field | Curriculum source |
| --- | --- |
| `grade` | K1-K3, P1-P6, S1-S6 |
| `subject` | EDB subject name, stored as enum-compatible English string |
| `kla_id` | Internal KLA key for filtering and dashboards |
| `topic` | App-level mapping layer, derived from OCR / AI / parent confirmation |
| `skill` | App-level learning objective or sub-skill, must cite source node when available |
| `source_ids` | Official EDB source IDs above |
| `status` | Implementation or transition note, such as Primary Science rollout |

## Implementation Notes

- Frontend structured data: `src/data/curriculum.ts`
- Backend structured data: `backend/app/curriculum_catalog.py`
- Backend endpoint: `GET /api/curriculum/catalog`
- Distributed syllabus generator: `scripts/generate_syllabus_docs.py`
- OCR review prompt now asks Gemini to pick from HKEDB-aligned subjects for the child grade.
- Quiz generation prompt includes subject, KLA, strands and official source IDs before generating practice items.
- Coach learning map is profile-bound: it normalises `child.grade` and displays only subjects for that exact grade, e.g. S3 shows S3 subjects only.
- Parent confirmation remains required; app-generated topic / skill mapping is not treated as official EDB assessment.
